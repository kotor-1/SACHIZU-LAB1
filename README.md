# SACHIZU LAB — CMJ / RJ / 10m

無料のブラウザ用・公開テスト版です。動画は端末内で解析し、アプリからサーバーへアップロードしません。個人動画・解析結果・選手データ・非公開の学習モデルはこのリポジトリに含みません。

- CMJ：録画またはカメラから跳躍高を推定。
- CMJカメラ：撮影中に骨格・推定重心を表示し、着地後の静止で高さを自動表示。停止せず連続計測できます。対応ブラウザでは別スレッドでGPU推論し、未対応時はCPU／互換処理を使用。実効fpsとフレーム間隔を表示します。
- ライブv4ではFullモデルを優先し、準備中の12コマの推論時間中央値が25msを超えた場合だけLiteへ切り替えます。切り替えはReadyより前のみ。実際の撮影fpsや計測精度を保証する基準ではありません。Fullで改善するかは撮影条件にも依存します。
- RJ表示：解析中・解析後の再生に骨格と推定重心を重ねます。必要な点が取れないフレームには重心を表示しません。
- RJ：動画と両足／右足／左足を選び「入力なしで自動解析」。身長・基準物・離地や着地の手動入力は不要です。足元の元フレームから時刻を自動推定し、成立した各回のRSIの平均・最大・採用回数を表示します。全回が成立しない場合は部分平均と採用した回を明示し、欠測を0や他の回で埋めません。認識した跳躍数で集計し、最初の1回はRSI対象外です。JSONには結果と足元の診断を保存します。
- RJの自動判定：骨格で見つけた足元を元動画から読み直し、明るい靴／暗い靴の双方を試します。靴と地面に明暗差があり、足が分離して見える映像向けの試験機能です。画像の判定条件に合わない時刻は採用しません。自動判定の成立は精度の保証ではなく、測定器との独立した精度検証は未実施です。画面を閉じたり別アプリへ切り替えると解析を中止します。
- 10m：スタート・ゴールの位置と最初の遊脚の着地を登録。通過時間・歩数・脚の入れ替わり間の骨盤移動距離を推定。最初の着地と直後の入れ替わりは同じ1歩です。

## ローカル実行

Node.js 22以降で `npm ci`、`npm run dev` を実行し、表示されたURLの `/SACHIZU-LAB1/` を開きます。`npm test` で回帰テスト、`npm run build` で公開用ビルド、`npm run preview` で確認できます。

## 公開

GitHub Pagesのブランチ公開を使用します。Settings → Pages → Source は Deploy from a branch、gh-pages / (root) です。公開先は https://kotor-1.github.io/SACHIZU-LAB1/ です。

mainはソース、gh-pagesは `npm run build` で作った `dist-public` の内容のみです。更新時はテストとビルド後に、gh-pagesの別チェックアウトへビルド成果物を同期し、差分を確認してcommit/pushします。`.nojekyll` も含めてください。mainへのpushだけでは公開物は更新しません。

Actions方式は手動起動用の設定を残していますが、現行の公開では使用しません。切り替える場合はPagesのSourceをGitHub Actionsに変更してください。

リポジトリ名や公開パスを変える場合は `DEPLOY_BASE_PATH` をビルド時に設定してください。GitHub Pagesの無料枠・利用条件・容量／帯域上限が適用されます。独自ドメインは不要です。

## 計測の制約

研究・試験機能で、測定器同等の精度は未検証です。表示が出ることと精度が確認されたことは異なります。医療・競技公式判定用ではありません。

スマホを固定し、明るい場所で全身・足元を映してください。録画は元のフレームと通常の時間軸を保持してください。スロー書き出し倍率は自動補正しません。RJは撮影条件によって採用回数や値が変わります。10mの距離換算は横に近い固定撮影を前提とし、接地点間の実測ストライドではありません。

MOV/MP4の元フレーム解析はWebCodecs対応とコーデック対応が必要です。iPhone・Android全機種での動作は未検証です。端末性能により待ち時間が変わります。モデルの初回読み込みには通信が必要です。

CMJは正面撮影を推奨します。横向きで奥側の関節が隠れる動画は、骨格が一部表示されても全身重心の条件を満たせず結果が出ない場合があります。不鮮明なコマは同じ元フレームの人物領域を再推定しますが、前後のコマによる補間や信頼度基準の緩和はしません。解析に失敗したときは「解析できない原因を保存」で診断情報を保存できます。

## プライバシーと保存

CMJの小さいジャンプには、従来の計算が成立しない場合に短い空中区間を使う試験的推定を追加しています。5cm・60fps、10〜15cm・30fpsの合成波形による動作テストであり、児童の実測精度を保証しません。観測不足や不安定な推定では高さを表示しません。スマホは腰付近の高さで固定し、跳躍中も全身が収まるようにします。「録画も残す」は任意で、オンの場合のみ最長20秒で停止します。

会員登録・広告・アクセス解析なし。動画・手動登録・解析結果はブラウザ内で処理します。必要な結果はJSON/CSVの保存ボタンで保存してください。ページを閉じると未保存の結果は失われます。サイト配信時のIP等はGitHubが処理する場合があります：[GitHubプライバシーポリシー](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。
