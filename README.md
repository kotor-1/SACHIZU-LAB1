# SACHIZU LAB — CMJ / RJ / 10m / ハードル / 投擲 / 走高跳 / 走り幅跳び / カーブスタート

無料のブラウザ用・公開テスト版です。動画は端末内で解析し、アプリからサーバーへアップロードしません。個人動画・解析結果・選手データ・非公開の学習モデルはこのリポジトリに含みません。

このサイトは CMJ・RJ・10m（Sprint）と、トップページの「種目解析」のハードル・ジャベリックスロー／やり投げ・砲丸投・走高跳（はさみ跳び）・走り幅跳び（助走の最後）・カーブスタートです。走り幅跳びの空中動作・着地や、ほかの跳躍種目の動作解析は含みません。

- CMJ：録画またはカメラから跳躍高を推定。左右のつま先が床から離れる瞬間と、空中の重心の最高点までの時間で計算します（ライブv8）。カメラで計測するときは、止まったり合図を待ったりせず、好きなタイミングで続けて跳べます。スマホは縦向き・横向きのどちらでも使えます。姿勢モデルはライブ・録画ともFull。PUSHなど他の機器とは基準が異なり、低めに出ます。
- RJ：両足RJの録画またはカメラ（端末内で録画して解析）から平均RSIを推定。つま先の軌跡で周期を区切り、靴底の画像で離地・着地を測ります（靴底接地v2）。床の影で靴底を正しく測れない動画では、つま先の軌跡から計算し、その旨を表示します。平均に加えて「最後3回の平均」と「最高」も表示します。身長・基準物・コマの手動指定は不要。`?lab=rj`（以前の `?lab=rj-toe-cycle` も同じ画面）。
- 10m（Sprint）：「スタート10m」と「最高速度区間（例：50〜60m）」。2本の線を設定するだけで、録画から通過時間・平均速度・歩数・ピッチ・平均歩幅を推定（解析v10）。カメラでのリアルタイム計測では、通過時間と平均速度だけを走るたびに表示します。「クラウチングスタート」では、ブロックから5歩目まで（映っている歩だけ）の接地・滞空・ピッチと姿勢の角度を出します。判定した接地・離地は「確認」で1コマ単位で直せ、数値がすぐ変わります。
- ハードル（種目解析）：真横から撮ったハードル1台の踏切から着地まで。重心が最高点になる位置（ハードルの何cm手前か）、空中時間、踏切・着地の接地時間、踏切：着地の距離の割合、各局面の姿勢の角度。踏切距離・着地距離とバーの上の高さは参考記録。`?lab=hurdle`。
- ジャベリックスロー・やり投げ（種目解析）：真横から撮った投げのブロック脚（前足）の接地からリリースまで。ブロック脚の膝の角度（接地・最も曲がった時・リリース）、接地からリリースまでの時間、上体の傾き、ブロックでの減速、リリースの角度・高さ・やりの向き（迎え角）と、リリース速度（目安）。`?lab=jav`。
- 砲丸投（種目解析）：グライドまたは立ち投げ（回転投法は対象外）。局面ごとの時間（グライド・移行・突き出し）、パワーポジションの姿勢と足幅、グライドの距離、上体の起こし、膝の角度、リリースの角度・高さと、リリース速度（目安）。`?lab=shot`。
- 走高跳（種目解析）：踏切の動きの真横から撮った、はさみ跳びの踏切。支柱とバーを物差しに、踏切の離地での重心の上向きの速さと空中で上がった高さ（最高点も）、最後の2歩のリズム、踏切接地の後傾。`?lab=highjump`。
- 走り幅跳び（種目解析）：真横から撮った助走の最後と踏切。踏切に入る最後の2歩の助走速度と踏切接地の瞬間の速さ、離地の鉛直速度・水平速度（いずれも目安）、踏切角度（参考）、最後の2歩のリズム、踏切接地の脚の角度・上体・膝。踏切板と砂場が映っていれば、その間の距離を物差しにできます。`?lab=longjump`。
- カーブスタート（種目解析）：200 m・400 m・リレーの曲走路からのスタートを、ブロックの真後ろから撮影。カーブの線に惑わされずにブロックからまっすぐ出られたか（理想の道より内側に入ったか）、出た向き、その後カーブに沿えたか（内側のラインからの距離）、内傾。走った軌跡を動画の上と真上から描きます。レーン幅1.22 mが物差しです。白線に点を置くと、見つかった白線とスタートラインを画面に描きます。撮影中に画面が少し動いても補正します。`?lab=curve`。

## 計測の制約

RJに「FullとHeavyを比較」を追加しました。同じ元動画・全フレームをFull→Heavyの順に処理し、RSI計算側を固定して比較します。通常解析はFullのままです。Heavyは初回約30MBの受信があり、数分以上かかる場合があります。画面を開いたまま待ち、比較完了後に両モデルの採用回数・追跡率・処理時間を確認し、比較JSONを保存できます。高いRSIや多い採用回数は精度の保証ではありません。RTMPose/RTMWの比較はまだ含みません。

RJ自動解析v3は、合格した9条件（3つの画素閾値×3つの時間窓）の時刻の中央値を使用します。特定の1条件だけの時刻に依存しないための修正で、合格基準の緩和ではありません。端末間の一致や実測精度を保証するものではなく、採用された回が違う平均同士の比較には注意してください。

研究・試験機能で、測定器同等の精度は未検証です。表示が出ることと精度が確認されたことは異なります。医療・競技公式判定用ではありません。

スマホを固定し、明るい場所で全身・足元を映してください。録画は元のフレームと通常の時間軸を保持してください。スロー書き出し倍率は自動補正しません。RJは撮影条件によって採用回数や値が変わります。10mの距離換算は横に近い固定撮影を前提とし、接地点間の実測ストライドではありません。

MOV/MP4の元フレーム解析はWebCodecs対応とコーデック対応が必要です。iPhone・Android全機種での動作は未検証です。端末性能により待ち時間が変わります。モデルの初回読み込みには通信が必要です。

CMJは正面撮影を推奨します。横向きで奥側の関節が隠れる動画は、骨格が一部表示されても全身重心の条件を満たせず結果が出ない場合があります。不鮮明なコマは同じ元フレームの人物領域を再推定しますが、前後のコマによる補間や信頼度基準の緩和はしません。解析に失敗したときは「解析できない原因を保存」で診断情報を保存できます。

## プライバシーと保存

CMJの小さいジャンプには、従来の計算が成立しない場合に短い空中区間を使う試験的推定を追加しています。5cm・60fps、10〜15cm・30fpsの合成波形による動作テストであり、児童の実測精度を保証しません。観測不足や不安定な推定では高さを表示しません。スマホは腰付近の高さで固定し、跳躍中も全身が収まるようにします。「録画も残す」は任意で、オンの場合のみ最長20秒で停止します。

会員登録・広告・アクセス解析なし。動画・手動登録・解析結果はブラウザ内で処理します。必要な結果はJSON/CSVの保存ボタンで保存してください。ページを閉じると未保存の結果は失われます。サイト配信時のIP等はGitHubが処理する場合があります：[GitHubプライバシーポリシー](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。

第三者ソフトウェアとモデルの出典・ライセンスは [THIRD_PARTY_NOTICES](public-app/THIRD_PARTY_NOTICES.md) を参照してください。

## 種目解析：ハードル（2026-10-05、試験機能）

- トップページの「種目解析」→「ハードル」。真横から固定して撮った動画（1秒120コマ以上、240推奨）で、ハードル1台と、その手前1〜2歩から着地の後1〜2歩までを映します。最初のコマで、縦の線をハードルの位置に、横の線2本をバーの上端と足元（地面）にドラッグで合わせ、ハードルの高さ（60・70・76.2・83.8・91.4・99.1・106.7cm）を選んで「解析する」。走る向きは自動で判定します。解析の後に線や高さを変えた場合は、動画を読み直さずに計算し直せます。
- 縮尺：ハードルの高さと、上端・足元の線の間の画素数から求めます（ハードルが物差し）。重心の放物線の曲がり方（重力加速度）からも縮尺を求め、12%を超えて違うときは、高さの選択や線の位置を確かめるよう表示します。
- 重心最高点：骨格の各部位の位置と質量の割合（de Leva 1996）から重心を求め、踏切から着地までの空中の重心に放物線を当てはめて最高点を決めます。「ハードルの何cm手前で最高点になったか」「バーの何cm上を通ったか（最高点・ハードルの線を越える時）」と、重心の軌跡のグラフ・画像を表示します。バーの上の高さは重心の高さで、体の一番低い所とバーの隙間ではありません。
- メインの指標（結果の上）：重心最高点の位置（約○cm手前、±5cm、ハードル上を通る何秒前か）、空中時間、踏切の接地時間、踏切：着地の距離の割合（画素の比で、縮尺を使わない）。
- 参考記録：踏切距離（踏切のつま先→ハードル）・着地距離（ハードル→着地のつま先）、重心のバーの上の高さ。オプトジャンプで計測したハードル走のレポート（4人、3台目）と比べると、空中時間・接地時間は0.01秒前後、踏切：着地の割合は3人で一致しましたが、踏切距離は7〜11cm長く出ました（カメラが少し下を向いてハードルが低く写ったため。選手がレーンのどこを走るかでも変わる）。そのため距離はメインの指標にしていません。
- 時間：踏切の1歩前・踏切・着地・着地の次の接地時間と、その後の空中時間（踏切の離地から着地までが空中時間）。
- 姿勢：踏切の接地・踏切の離地・重心最高点・ハードル上・着地の画像に、体幹・脛・リード脚の大腿と膝・踏切脚の膝の角度を描きます。抜き脚は体の横に開くため、角度を出しません。スロー再生・判定した瞬間への移動はクラウチングスタートと同じです。
- 見方のポイント：研究で報告されたトップ選手の値（重心最高点の位置、空中時間、着地の膝・体幹）と比べて表示します。選手ごとの目標ではありません。
- 接地・離地・角度・重心はRTMPose、選手を見つけて追うのはMediaPipeです。真横から1秒240コマで撮った5人の踏切・着地（10回）で、映像の瞬間との差は接地 最大0.015秒、離地 最大0.010秒、接地時間 最大0.008秒、空中時間 最大0.010秒（ChromeとSafari系で同じ）。重心最高点の位置は計算の範囲を変えても±3cm、ChromeとSafari系の差は1cm以内でした。上端の線を3画素ずらすと、踏切距離は約4cm、バーの上の高さは約2cm変わります。重心の絶対的な正しさ（モーションキャプチャとの比較）とスマートフォン実機での確認は未実施です。

## 種目解析：ジャベリックスロー・やり投げ／砲丸投（2026-10-05、試験機能）

- トップページの「種目解析」→「ジャベリックスロー・やり投げ」または「砲丸投」。投げる方向に対して真横から固定して撮った動画（1秒120コマ以上、240推奨、全身と足元）で、ジャベは前足の接地の少し前から、砲丸投は構えからリリースの後までを映します。最初のコマで線を選手に合わせ、投げる手（右投げ・左投げ）と、砲丸投は投法（グライド・立ち投げ）を選んで「解析する」。投げる向きは自動で判定します。
- ジャベ：ブロック脚の膝の角度（接地・接地からリリースまでで最も曲がった時・リリース）と、ブロック脚の接地からリリースまでの時間。後ろ足（最後の1歩）の時間は、着地の後も足が滑って判定が0.1秒ほど遅れたため出していません。
- 砲丸投：グライドは、後ろ足が離れてから着くまで（グライド）、後ろ足の接地から前足の接地まで（移行）、前足の接地からリリースまで（突き出し）の時間と、前足の接地（パワーポジション）の後ろ脚の膝・上体の傾き。立ち投げは、腰が最も後ろにきてからリリースまでの時間と、その時の姿勢。リリースの前脚の膝・上体も出します。
- リリースは、選んだ側の手首が最も高くなった瞬間です。スロー再生で用具が手から離れたコマに止めて「表示中のコマをリリースにする」を押すと、そのコマで計算し直します。接地は、つま先が地面の高さで止まった瞬間です。脚は骨格の左右ではなく、リリースの時に着いている一番前の足（前足）の場所で決めます。
- 見方のポイント：研究で報告されたトップ選手の値と比べて表示します（やり投げ：2017年世界選手権の報告、Camposら2004、田内ら2012、瀧川ら2020。砲丸投：2017年世界選手権女子決勝のグライドの選手、田内ら2006、Mastalerz・Sadowski 2022）。ジャベリックスローの研究値、パワーポジションの角度、立ち投げの時間は、比べられる研究の値が見つからなかったため表示していません。選手ごとの目標ではありません。
- 真横から1秒120〜240コマで撮った7本（ジャベ4本、砲丸投グライド3本）をChromeとSafari系で解析し、映像で見た瞬間と比べると、前足の接地は0〜3コマ遅く、砲丸投の後ろ足は離地が0〜1コマ早く・接地が0〜3コマ早く、リリースは2コマ早い〜3コマ遅いでした（120コマ/秒で1コマ＝0.008秒）。時間は±0.03秒ほど、膝が速く動く瞬間の角度はコマのずれで数度変わります。立ち投げ・左投げ・右から左へ投げる実際の動画と、スマートフォン実機での確認は未実施です。

### 投擲 v2：リリースと姿勢の項目（2026-10-06、試験機能）

- 項目：ジャベは、リリースの角度・高さ・やりの向き（姿勢角）と迎え角、上体の傾き（数値）、ブロックでの減速（重心の前に進む速さが、ブロック脚の接地からリリースまでに何%落ちたか）。砲丸投は、リリースの角度・高さ、足幅（パワーポジション）、グライドの距離、上体の起こし、後ろ脚の伸び、前脚の膝（接地・最も曲がった時）。
- リリース：解析の後、リリースの前後の映像をもう一度読み、背景と違う所から、手の近くを出て重力で落ちながら飛ぶ用具の道筋を探して、リリースの瞬間の速さと角度を出します（やりは後ろの端、砲丸は中心）。用具が手から離れた後も0.05秒（120コマ/秒で6コマ）以上映っている必要があります。リリースの画像に用具の位置を緑の点で重ねて表示します。
- **リリース速度とm単位の値は、動画から推定した目安です。** 縮尺は、骨格の胴（肩の中点〜腰の中点）の長さと、入力した身長（任意）の比です。記録から求めた速度（ジャベリックスロー：前田・丹松 2008 の飛距離と初速度の関係式、砲丸：記録からの逆算）と比べた差は、4人・6試技で平均7%・最大13%だったため、時速は「約63km/h（目安の幅 57〜69km/h）」のように±10%の幅を付けて表示します。スピードガンなどとの比較はしていません。角度は縮尺によらず、速度より確かです。同じ選手を同じ撮り方で撮った試技どうしなら、幅を超える違いは変化と見てよい目安です。
- 結果のタブは、ポイント・姿勢・数値・リリース・スローの5つです。参考値は、2017年世界選手権のバイオメカニクス報告（Bennettら・Dinsdaleら 2018）、Camposら 2004、瀧川ら 2020、加藤ら 2019、Schaa 2010 などです（選手ごとの目標ではありません）。

## 種目解析：走高跳（はさみ跳び）（2026-10-06、試験機能）

- トップページの「種目解析」→「走高跳（はさみ跳び）」。三脚で固定したスマホを水平に置き、踏切の動きの真横から、踏切の3歩前から踏切の後の上昇までを撮影します（1秒240コマ推奨）。左右両方の支柱の根元とバーが画面に入るようにしてください。最初のコマで、左右の支柱それぞれの「バーがのっている所」と「根元」の4点をドラッグで合わせ（選んだ点は▲▼◀▶で細かく動かせます）、バーの高さ（cm）を入れて「解析する」。解析の後に点やバーの高さを変えた場合は、動画を読み直さずに計算し直せます。
- 物差し：スマホの焦点距離（iPhoneの通常の画角、35mm換算27mm）と、4点・バーの高さから、カメラの高さ・向き・位置を計算します。踏切足が地面に着いた場所と1歩前の足の場所を結ぶ向きを跳躍の面として、重心の高さをメートルに直します。カメラが斜めでも、選手のいる距離で高さを測ります。計算した支柱の間隔が規格（約4m）から外れたときは、バーの高さと点の位置を確かめるよう表示します。
- メインの指標（記録とのつながりが研究で示されたもの）：踏切の離地での重心の上向きの速さ（m/s）と空中で上がった高さ（cm、重心の最高点も）、最後の2歩のリズム（接地から次の接地までの1歩の時間）、踏切接地の後傾（踏切足の足首から重心への線の鉛直からの角度）。上向きの速さは、離地の直後0.1秒の重心の高さに重力で減速する放物線を当てはめて求めます（バーの上では骨格が乱れるため、それより後は使いません）。
- 参考：踏切の接地時間、踏切脚の膝の角度（接地・最も曲がった時・離地）、体幹の傾き、振り上げ脚の大腿、跳び出しの角度、踏切接地の横の速さのうち上向きに変えた割合。参考値は中学生のはさみ跳び（吉田・藤田 2017）などの研究の値で、選手ごとの目標ではありません。
- 精度：開発に使った2本（はさみ跳び、バー120cm）で、計算した支柱の間隔は4.13m・4.20mでした。見込みの誤差は上向きの速さ±0.1〜0.15m/s、上がった高さ±3〜4cm（バーの高さが正しい場合）。接地・離地は映像との差が踏切の接地時間で最大0.008秒。フォースプレートなどの真の値との比較はしていません。背面跳びは対象外です（曲線助走で跳び出しの向きが変わり、今回の方法では安定しません）。

## 種目解析：カーブスタート（2026-10-06、試験機能）

- トップページの「種目解析」→「カーブスタート」。三脚で固定したスマホを、ブロックの真後ろ（スタートラインの3〜5 m後ろ、高さ1.3 m以上）に置き、構えから選手が遠ざかるまで撮影します。選手のレーンの左右の白線が、ブロックから15 m先まで映るようにしてください。最初のコマで、選手のレーンの内側と外側の白線に、スタートラインと交わる所で点を合わせて「解析する」。点を変えた場合は、動画を読み直さずに計算し直せます。
- 物差し：レーン幅（1.22 m、規則で±1 cm）と、内側・外側の白線（中心が同じ円）、スタートライン（半径の向き）、動画に記録された焦点距離から、カメラの高さ・向き・位置を計算します。足の着いた位置は、その場所でレーンを直角に横切る線を物差しにして、内側のラインからの距離を出します。
- 判定（まっすぐ出られたか）：理想の道は、スタート位置から内側から20 cmの線に接するまっすぐの線を進み、接点からその線に沿う道です（外寄りからは最短の道。ブロックを斜めに置くのは最短距離を取るためと規則の解説にもあります）。カーブの線に引き込まれて早く曲がると、接点の前後で体がこの道より内側に入ります。接点の2 m先までに12 cmより内側に入ったら「早く曲がった」と表示します。体の位置は、各歩の接地の中ほどで骨盤の真下にあたる地面の点です（内傾すると足は体より外に着くため、足跡だけでは見誤ります）。
- そのほか：出た向き（接点までの通り道と理想の線の向きの差）、接点の後の内側のラインからの距離（最大45 cm以上で「ふくらんだ」）、体の内傾（足から骨盤への線と鉛直の角度。まっすぐの区間と曲がってから）。
- 精度：4本の開発用の動画（4K・60コマ/秒）で、焦点距離や半径の仮定を変えても、レーン内の位置±1 cm・出た向き±0.1°・内傾±0.5°しか変わりません。ChromeとSafari系（WebKit）で判定は同じでした。答えのわかっている合成データで、まっすぐの判定・出た向き・内傾を確かめています。3次元計測などの真の値との比較はしていません。後ろからは接地・離地の時刻を決められないため、時間は出しません。

## 走り幅跳び v2：踏切板と砂場の物差し（2026-10-06、試験機能）

- 解析の後に「踏切板と砂場の物差し（任意）」で、踏切線（踏切板の砂場側の端）と砂が始まる所が、助走路の奥の縁・手前の縁と交わる4点を合わせ、その間の距離（既定2 m）を入れて「物差しを使う」を選ぶと、その距離から速さの縮尺を求めます。点は踏切のコマの上で、拡大した画面でドラッグし、矢印で1画素ずつ動かせます。選手が助走路のどこを走ったか（手前寄り・奥寄りで縮尺が最大±8%変わる）は、踏切足の位置から自動で考えます。
- **v1の速さは1〜2割遅く出ていました。** 開発に使った4本で2 mの物差しと比べると、v1の縮尺（重力から・身長から）は11〜23%大きく、速さが遅く出ていました。重力からの縮尺は、骨格から求めた重心の空中での道筋が放物線からわずかにずれて1割ずれ、身長からの縮尺は、空中で胴が長く映るコマを基準にしていたためです。v2では、身長からの縮尺を踏切前2歩の胴の長さから求め（物差しとの差−9〜+4%）、縮尺は物差し→身長→重力の順に使います。目安の幅は物差し±5%・身長±10%・重力±15%です。

## 種目解析：走り幅跳び（助走の最後）（2026-10-06、試験機能）

- トップページの「種目解析」→「走り幅跳び（助走の最後）」。三脚で固定したスマホで、助走路の真横から、踏切の2〜3歩前から踏切の後の空中までを撮影します（1秒120コマ以上、240推奨。着地は映らなくてかまいません）。選手と走る向きは自動で見つけます。身長（任意）を入れておくと、踏切の後の空中が短くしか映っていない動画でも速さが出ます。
- メインの指標（記録とのつながりが研究で示されたもの）：助走速度（骨格から求めた重心が、2歩前の接地から踏切の接地までに前へ進んだ速さ）と踏切接地の瞬間の速さ、離地の鉛直速度。研究では助走速度が記録と最も強く結びつきます（太田ら 2010：r = 0.81〜0.86）。離地の鉛直速度も女子で記録と結びつきます（Nemtsevら 2016：r = 0.61）。
- 参考：離地の水平速度、踏切角度（最適は人ごとに20.9〜25.4°で、目標にする値ではありません。Linthorneら 2005）、最後の2歩のリズム（最後の1歩の時間÷その前の歩の時間）、各歩の接地・空中の時間、踏切の接地時間、踏切接地の脚の角度（股関節→足首の線と水平）、上体と膝。歩幅は出しません。
- **速さは動画から推定した目安です。** 縮尺（v2）は、踏切板と砂場の物差し、身長と踏切前2歩の胴の長さ、踏切の後の空中の重心の放物線（重力）の順に、得られるものを使います。どれを使ったかを画面に表示します。光電管などの正解との比較はしていません。ChromeとSafari系の差は助走速度で2%以内でした。
- 結果のタブは、ポイント・姿勢・数値・スローの4つです。

## Sprint：クラウチングスタート（2026-10-03、試験機能）

- 歩ごとの変化：1歩ごとの値を1つの表にまとめ、接地時間・滞空時間（トップ選手1人の例を点線で表示）、ピッチ、接地時の脛と体幹の角度のグラフを、選んだ1枚ずつ表示します。

`?lab=rj-toe-cycle` の平均RSIを、つま先の型だけの推定から、靴底の画像で測った離地・着地による計算に変えました。つま先の骨格点は、踵が上がって足が靴の先で回転し始めると、靴がまだ床に着いていても上がるため、型は離地を早く取り、接地時間を短く・RSIを高く出していました（40周期の目視確認で平均約1.3コマ早い）。姿勢推定と同じ1回の読み込みで足元の小さな範囲だけ靴の輪郭を調べ、靴底が速く上がり始めた瞬間を離地、速い下降が止まった瞬間を着地とします。つま先で押している間のゆっくりした転がりは離地に数えません。靴底を確認できない周期は型の値で補わず、3周期未満なら保留します。保存JSONには靴底データも保存され、再計算に使えます（靴底データのない古いJSONでは平均RSIを表示しません）。頂点選択v4（前後の両足軌跡を確認）も同時に反映しています。2026-09-30から、ホームの「RJ」もこの方式です（以前の自動RJの画面は公開サイトから外しました）。精度は未検証で、PUSHなど他の機器とは定義・集計が異なります。

## 10m スプリント v7：背景に人がいる動画での追跡・スタート・歩数

- **追跡**：

## 10m スプリント v6：最初の1歩の入力を廃止・歩数の誤計数を修正
