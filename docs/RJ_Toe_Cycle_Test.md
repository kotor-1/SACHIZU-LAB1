# 両足RJ・連続軌跡によるRSI予測（試験版）

試験画面: https://kotor-1.github.io/SACHIZU-LAB1/?lab=rj-toe-cycle

録画を選び「入力なしでRJを解析」を押します。身長・基準物・接地離地の手動入力は不要。動画は端末内で処理し、送信しません。

Fullモデルの骨盤＋左右つま先の連続軌跡から、頂点間周期ごとの内部時間割合を推定します。踵を必須にせず、接地・離地を個別コマで分類する旧方式も使いません。ただし接地に相当する時間はモデル内部で推定します。RSIの実測や、科学的に精度検証された代替計測器ではありません。

固定カメラ・全身と左右のつま先が映る、通常時間軸の120/240fps元動画を使用。両足RJ用です。ページ内の再計算は同じ骨格を再利用しますが、動画変更・ページ終了で消えます。結果をJSON保存してください。

試験では認識頂点数、算出周期数、同じ動画での再現性を確認してください。11頂点は10周期であり、各跳躍RSIや最後3回平均とは集計が異なります。欠測は補完しません。

通常RJ、CMJ、10mの解析方式は変更していません。この試験版は専用URLからのみ開きます。
